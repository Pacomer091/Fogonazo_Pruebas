# Fogonazo OS — Web Comercial (Fogonazo.com)

Página web publicitaria y calculadora interactiva para captación de restaurantes de **Fogonazo OS**.

## 🌐 Módulos del Repositorio
- `index.html`: Landing page B2B con métricas de conversión, ahorro directo frente a agregadores (Glovo, Uber Eats) y presentación de producto.
- `calculadora.html`: Calculadora de ahorro mensual y anual según el ticket medio y volumen de pedidos.
- `css/style.css`: Sistema de diseño moderno, tipografías y animaciones.
- `img/`: Identidad corporativa y logotipos.
